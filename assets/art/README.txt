backd8 pixel art - generated by assets\make-art.ps1 (re-run it to regenerate everything here).
All art is original. Palette: Win98 16 colours + #DFDFDF + teal #40A0A0. Light from top-left, 1px black outline.

LOADING (PowerShell + WPF):
  . "$PSScriptRoot\assets\art\load-art.ps1"
  $src = Get-ArtBitmap 'art-signin'          # frozen BitmapImage, name = file name without .png
  $img = New-ArtImage 'icon-folder-32'        # Image control with NearestNeighbor already set
If you put the BitmapImage in your own <Image>, you MUST set
  [System.Windows.Media.RenderOptions]::SetBitmapScalingMode($image, 'NearestNeighbor')
  (XAML: RenderOptions.BitmapScalingMode="NearestNeighbor", SnapsToDevicePixels="True", UseLayoutRounding="True")
otherwise WPF smooths the pixels. Display at native size or an integer multiple.
